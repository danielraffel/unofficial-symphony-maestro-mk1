Remove Existing Apogee Software First

Symphony Maestro conflicts with the original Apogee drivers. If both are installed, neither will work correctly. The installer will check and block installation if it detects active Apogee drivers.

How to Check

Open Finder and look for:

  • Apogee Maestro 2 or Apogee Control in Applications
  • Any files in /Library/Audio/Plug-Ins/HAL/Apogee/

How to Remove

  1. Download the official Apogee installer:
    Symphony I/O Release 5.5
  2. Open the DMG and choose Uninstall
  3. Keep the DMG in case you want to revert later
  4. Run this installer again

Why Apogee’s own installer? Maestro is an independent project and we don’t bundle or maintain Apogee’s software. Using Apogee’s own uninstaller removes the conflicting drivers with the vendor’s own tool, and keeping that DMG means you can reinstall the original Apogee software anytime if you ever want to go back. We recommend keeping it.

If you've already removed the Apogee software, you can install this software.
