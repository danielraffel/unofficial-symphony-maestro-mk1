Remove Existing Apogee Software First

Symphony Maestro conflicts with Apogee’s original Symphony I/O drivers. If both are installed, they interfere with each other and can cause problems, including crashes. The installer will check and block a first installation if it detects them. An update of Maestro goes ahead, and Maestro’s Device Settings shows a warning until they are removed.

How to Check

Open Finder and look for:

  • Files in /Library/Audio/Plug-Ins/HAL/Apogee/Symphony Systems/
  • Symphony64Thunderbridge.kext, Symphony64.kext or SymphonyIOUSBOverideDriver.kext in /Library/Extensions/ (Apogee’s ThunderBridge, Symphony 64 PCIe and USB drivers)

Maestro doesn’t need Apogee Maestro 2 or software for other Apogee products removed, but Apogee’s Uninstall removes Apogee Maestro 2 too. If you use it with another Apogee interface, reinstall it from Apogee afterwards.

How to Remove

  1. Download the official Apogee installer:
    Symphony I/O Release 5.5
  2. Open the DMG and choose Uninstall
  3. Keep the DMG in case you want to revert later
  4. Restart your Mac, so Apogee’s kernel extension is no longer loaded
  5. Run this installer again

Apogee’s Uninstall also removes Maestro if it is installed, and resets macOS’s audio device settings. If you already had Maestro, running this installer again puts it back; check your audio device settings afterwards.

If you’re still blocked after uninstalling and restarting, or Apogee’s uninstaller won’t run on your Mac, see Removing Apogee’s original drivers in the Maestro user guide.

Why Apogee’s own installer? Maestro is an independent project and we don’t bundle or maintain Apogee’s software. Using Apogee’s own uninstaller removes the conflicting drivers with the vendor’s own tool, and keeping that DMG means you can reinstall the original Apogee software anytime if you ever want to go back. We recommend keeping it.

If you've already removed the Apogee software, you can install this software.
