Privacy Policy

Effective date: February 2026

Data Collection

Maestro controls locally connected Symphony I/O hardware over USB or ThunderBridge. It does not include an analytics or telemetry service.

Network Access

When checking for or downloading software updates, Sparkle contacts the configured update feed and download host. Those hosts receive ordinary network request information, such as your IP address. Hardware control operates locally.

Analytics

Maestro does not include any analytics, telemetry, or crash reporting frameworks.

Local Storage

Maestro stores user preferences (presets, window state) locally on your Mac using standard macOS mechanisms (UserDefaults, ~/Library/Application Support). These preferences are stored locally.

Contact

For privacy questions, contact the developer via the project repository.
