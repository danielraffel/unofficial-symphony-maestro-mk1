Acknowledgements

Maestro is built with the help of the following:

Apogee Electronics

Symphony I/O MK I firmware and USB protocol reference from the original Maestro 2 source code.

Apple Frameworks

  • SwiftUI — User interface
  • CoreAudio — Audio device communication
  • IOKit — USB hardware access
  • AppKit — macOS system integration
  • AudioServerPlugin — Virtual audio device

Third-Party Dependencies

The Maestro desktop app has no third-party dependencies — all app code is first-party Swift. The audio driver uses the following open-source library:

libASPL

github.com/gavv/libASPL
By Victor Gaydov and contributors.
Used in the AudioServerPlugin driver to implement the CoreAudio virtual audio device.
